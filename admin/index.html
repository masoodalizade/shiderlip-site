یک‌بار دسترسی مدیریت را آماده کن

  1. در گیت‌هاب، با حسابی که اجازهٔ ویرایش مخزن شیدرلیپ دارد وارد شو.
  2. روی «ساخت کد دسترسی» بزن. در Repository access گزینهٔ Only select repositories و مخزن shiderlip-site را انتخاب کن.
  3. مجوز Contents: Read and write را فعال کن. برای دکمهٔ به‌روزرسانی دستی RSS، Actions: Read and write هم لازم است. کد را بساز و در کادر ورود قرار بده.

کد فقط در حافظهٔ موقت این صفحه می‌ماند؛ با خروج یا بستن صفحه پاک می‌شود. محتوای سایت و فایل‌های بارگذاری‌شده عمومی‌اند؛ فایل فروشی یا اطلاعات خصوصی را اینجا بارگذاری نکن.
